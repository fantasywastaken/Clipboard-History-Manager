Clipboard History Manager is a fast, lightweight, keyboard-driven Windows clipboard manager built with C# and WPF on .NET 8. It runs quietly in the system tray, automatically captures every text snippet copied to the Windows clipboard using the native AddClipboardFormatListener Win32 API, and lets you recall any past entry with the global Ctrl+Shift+V hotkey registered through RegisterHotKey. The main window features live case-insensitive search, arrow-key navigation, one-click paste, and a right-click context menu for Copy, Pin, and Delete actions. Pinned entries appear at the top of the list and are persisted to %APPDATA%\ClipboardHistory\store.json as JSON via System.Text.Json so they survive across restarts, while unpinned history is capped at the most recent 100 items to keep memory usage tight. Duplicate copies are automatically deduplicated and promoted to the top. The app ships with a fully custom dark theme, hand-crafted WPF ControlTemplates for buttons, list items, scroll bars, and context menus, a programmatically drawn tray icon, single-instance enforcement via a named mutex, hide-on-close behavior, and true exit only from the tray menu. No third-party UI libraries, no external icon files, no telemetry.
